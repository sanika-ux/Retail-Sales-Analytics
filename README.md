# Retail Sales Analytics Dashboard

## Project Overview
This project analyzes retail sales performance using Python, SQL, and Power BI.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- Power BI

## Key Insights
- Technology category generated highest sales.
- West region produced maximum profit.
- Monthly sales showed upward growth trend.

## Dashboard Features
- KPI Cards
- Monthly Sales Trend
- Sales by Category
- Profit by Region
- Top Customers
- Interactive Filters

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis
3. SQL Business Queries
4. Power BI Dashboard Creation
5. Business Insights Generation
